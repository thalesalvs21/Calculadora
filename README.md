# Calculadora em Java

Calculadora simples de linha de comando, feita para praticar os fundamentos de Java: leitura de dados digitados pelo usuário, `switch` e saída formatada.

## Como funciona

O programa pede dois números e a operação desejada:

```
1 - Somar
2 - Subtrair
3 - Dividir
4 - Multiplicar
```

Depois mostra o resultado com quatro casas decimais.

## Tecnologias

- **Java**, usando `Scanner` para ler o que o usuário digita

## Como rodar

```bash
cd Calculadora/src
javac Main.java
java Main
```
